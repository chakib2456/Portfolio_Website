Georgia Bike Growth Map

Python pandas Jupyter Notebooks

A data visualization project that shows the growth of businesses closer to bike lanes in Georgia. The project uses Python Pandas and Jupyter notebooks to analyze data and create an interactive map that allows users to explore the growth of businesses in relation to bike infrastructure.
